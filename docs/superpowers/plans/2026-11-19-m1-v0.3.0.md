# M1 v0.3.0 (Albums, Artists, Search, Sort) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish M1: Albums and Artists tabs with detail screens, a global search, Songs sorting with an A–Z index, and "Go to Album/Artist" in the song context menu.

**Architecture:** One pure-Dart derivation (`Library.from(tracks)`) turns the existing drift track stream into songs, albums and artists; every screen, the search and the context menu read from that one snapshot through Riverpod. Detail, "See All" and search screens are pushed on the root navigator (tab bar hidden); the import overlay moves above the navigator so its sheets show over every screen. The Songs sort order is two new fields of `AppSettings`, stored in the existing key/value table.

**Tech Stack:** Flutter 3.50 / Dart 3.14, flutter_riverpod 3 (no codegen), drift. No new packages, no Rust or schema changes.

**Spec:** `docs/superpowers/specs/2026-11-19-m1-v0.3.0-design.md` (parent: `docs/superpowers/specs/2026-11-18-m1-import-library-design.md`). Read both; this plan does not repeat their rules.

## Review Focus

1. **Deleting the last song of an album/artist while its detail screen is open** → the screen pops itself, no red error screen, no exception in the test log (tests in Tasks 6 and 7).
2. **The library changes while a detail or search screen is open** (an import keeps adding tracks) → counts, track lists and search results update live (tests in Tasks 6 and 9).
3. **Albums with equal titles by different artists, and the same album with differently cased tags** ("Greatest Hits" by A and B; "Velvet Hours" vs "velvet hours" by Neon Harbor) → two albums in the first case, one in the second; the Album sort never interleaves the first pair (tests in Tasks 1 and 2).
4. **A short screen (landscape, small phone)** → the A–Z index collapses with `•` and never overflows (test in Task 4).
5. **Search input with spaces, accents and articles** (`"  arzte "` finds `Ärzte & Söhne`, `"the quiet"` finds `The Quiet Coast`, `"KÖLN"` finds `Grüße aus Köln`) → matches as a user expects (test in Task 9).

**Interfaces:**
- Consumes: Task 1 (`sortKey`, `foldKey`, `compareKeys`, `sortSongs`, `displayArtist`, `displayTitle`).
- Produces (`lib/library/library.dart`):
  ```dart
  typedef AlbumKey = ({String artist, String title}); // artist: artistGroupKey(albumArtist ?? artist); title: trim().toLowerCase()
  AlbumKey? albumKeyOf(Track t);   // null when album is blank
  String artistGroupKey(String? name); // displayArtist(name).trim().toLowerCase(): 'unknown artist' for blank/missing

  class Album {
    final AlbumKey key;
    final String title, artist;   // spellings of the first track
    final int? year; final String? genre; final String? coverFile;
    final List<Track> tracks;     // disc, track, title
    bool get hasMultipleDiscs;
  }
  class Artist {
    final String key, name;       // name: displayArtist of the first track by title
    final List<Track> songs;      // sorted by title (sortSongs title)
    final List<Album> albums;     // album.key.artist == key; year desc, unknown last, then title
    final String? avatarCover;    // newest album with a cover, else any song's cover
  }
  class Library {
    factory Library.from(List<Track> tracks);
    static final empty;
    final List<Track> tracks;     // as given
    final List<Album> albums;     // album artist, then title (compareKeys on sortKey)
    final List<Artist> artists;   // compareKeys on sortKey(name)
    Album? album(AlbumKey key);
    Artist? artist(String key);
    bool get isEmpty;
  }
  ```
  `artistGroupKey` is the single key function for both `Artist.key` (of the track artist) and `AlbumKey.artist`, so "Unknown Artist" albums resolve to the Unknown Artist entry. (`albumArtist ?? artist` treats a blank album artist like a missing one.)

  - `songsProvider` removed. Until Task 3, `SongsScreen` shows `sortSongs(library.tracks, SongSort.title)`.
  - `pumpApp(songs: …, songsStream: …)` keeps its parameters but overrides `tracksProvider`.
