# v0.3.1 Four Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the five-item tab bar with Home, Search, Library (Songs | Albums | Artists sub-tabs) and Playlists.

**Architecture:** `AppShell` keeps an `IndexedStack` of four tabs. The Library tab is a `LibraryTab` with a shared `Segmented` control over an `IndexedStack` of the three existing screens, so their queries and scroll positions survive switching. The shell owns the selected sub-tab so the "…" menu can show sorting only for Songs.

**Tech Stack:** Flutter 3.50 (`material_ui`, `cupertino_ui`), flutter_riverpod 3, flutter_test.

**Spec:** `docs/superpowers/specs/2026-11-19-v0.3.1-tabs-design.md` (mockups `docs/mockups/m2-v1/` 01–06).

## Global Constraints

- Imports: `package:material_ui/material_ui.dart` and `package:cupertino_ui/cupertino_ui.dart` (never `flutter/material.dart` / `flutter/cupertino.dart`).
- All code, comments, tests and UI strings in English.
- `flutter analyze` must report "No issues found!"; `flutter test` must pass.
- No new packages. No player features (mini player, queue, Play Next/Later) in this release.
- Tab order and icons: Home `CupertinoIcons.house` / `house_fill` · Search `search` · Library `square_stack` / `square_stack_fill` · Playlists `music_note_list`.
- Copy: Home empty state "Nothing here yet" / "Home arrives in a later version."; sub-tab labels "Songs", "Albums", "Artists"; title "Library".

## Review Focus

1. Empty library: the Library tab shows the existing empty state and **no** segmented control; the empty state's "Import Music" still works. → test in Task 2.
2. A query typed in Songs survives switching to Albums and back, and switching to the Search tab and back. → test in Task 2.
3. The sort options must not leak into other places: none on the Albums/Artists sub-tabs or on Home, Search or Playlists. → test in Task 2.
4. Large text (scale 1.35) on the Library tab: the segmented control and the title row must not overflow. → test in Task 2 (`text_scale_test.dart`).
5. The "Library" back label must not replace detail-to-detail labels (album title, artist name) or "Search". → test in Task 3.
