# v0.8.2 Player Gestures Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix auto-advance on iOS, add swipe-to-skip on the Now Playing cover and a heart in the mini player.

**Architecture:** The fix lives in `PlayerController._onCompleted`. The heart in Now Playing moves into a shared `LikeButton` widget used by both players. The cover swipe is a new `CoverCarousel` widget in `lib/player/cover_carousel.dart` that shows the current cover with the queue neighbours beside it and calls `next()` / `skipBack()`.

**Tech Stack:** Flutter 3.50, Riverpod 3, `material_ui` / `cupertino_ui` imports.

**Spec:** `docs/superpowers/specs/2026-11-25-v0.8.2-player-gestures-design.md`

## Global Constraints

- English in code, tests, UI strings; `flutter analyze` must report "No issues found!".
- Skip thresholds as the mini player: a quarter of the width (`0.25`) or a fling faster than `700` px/s; resistance factor `0.3` where there is no next song.
- Right swipe = `PlayerController.skipBack()`; left = `next()` only when `queue.hasNext`.

## Review Focus

- Shuffle on: the neighbour covers must be the play order's neighbours (`entries` are the play order), not the library order. Test in Task 3.
- Repeat all on the last song: the next neighbour is the first entry, and a left swipe wraps. Test in Task 3.
- A neighbour track without a cover (or deleted): the placeholder artwork shows, nothing crashes. Covered by `Artwork(file: null)`.
- A tap on the mini player heart must not open the player. Test in Task 2.
- The sheet's swipe-down-to-close keeps working (vertical drag on the cover is not claimed). Existing test "swiping down closes the player" stays green.

**Files:**
- Create: `lib/player/cover_carousel.dart`

**Interfaces:**
- Consumes: `playerProvider` (`queue.entries`, `nextIndex(auto: false)`, `previousIndex`, `hasNext`), `tracksProvider`, `storageProvider`, `PlayerController.next()` / `skipBack()`.
- Produces: `class CoverCarousel extends ConsumerStatefulWidget { const CoverCarousel({super.key, required double side}); }`, key `Key('player-cover')` on the gesture area; neighbour covers keyed `Key('player-cover-next')` / `Key('player-cover-previous')`, present only when there is a neighbour.

Behaviour: horizontal drag only (`onHorizontalDrag*`), cover translated by `dx`; neighbour at `±(side + gap)` (gap 24) translated with it, clipped by nothing so it slides in from the screen edge. On release past threshold: animate the strip to `∓(side + gap)`, then call the controller and reset `dx` to 0 without animation once the current track changed; else animate back to 0 (≈180 ms easeOut).
