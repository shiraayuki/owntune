# v0.7.2 Home: For You Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home becomes the start tab with For You (tiles of recently played sources, Continue listening, Shuffle All/Liked, On Repeat, Recently Added, Rediscover, Never Played, full-list pages) and a Stats placeholder, built from the v0.7.1 play history with fallbacks for a young history.

**Architecture:** `HomeRepository` runs two watched SQL aggregates over `plays`. A pure `buildForYou(...)` resolves them against `Library`, playlists and liked songs, applies the fallbacks and limits, and returns a `ForYou` view model. `forYouProvider` feeds it to the widgets. The shell starts on Home and shows `greeting(now)` as its title there.

**Tech Stack:** Flutter 3.50 / Dart 3.14, flutter_riverpod 3 (no codegen), drift (`customSelect().watch()`), flutter_test with `pumpApp`.

**Spec:** `docs/superpowers/specs/2026-11-24-v0.7.2-for-you-design.md` (read it first; it is the authority). Mockups: `docs/mockups/home-v1/01-for-you.html`, `02-for-you-scrolled.html`, `05-empty.html`, styles in `home.css`.

## Global Constraints

- **Imports:** use `package:material_ui/material_ui.dart` and `package:cupertino_ui/cupertino_ui.dart` (icons: `CupertinoIcons`).
- **Language:** everything in English. `flutter analyze` must report "No issues found!", and `dart format` must leave no changes.
- **Testability:** logic must be testable without Rust; dependencies go through providers that tests override (`pumpApp` in `test/support/fakes.dart`).
- **Album source keys:** `plays.source_key` holds `"<artistKey>\u0000<titleKey>"`. SQL compares and groups it only by equality, and splitting happens in Dart.
- **Time:** use the injected `clockProvider` for every "now". Never call `DateTime.now()` in Home code.
- **Values from the spec:**
  - Tiles: max **6**.
  - Rows: max **10** items, and full lists max **50**.
  - On Repeat window: **30 days**, where `since` = local midnight today − 30 days. The fallback applies when fewer than **4** songs resolve.
  - Rediscover: `playCount >= 3`, last played more than **60 days** ago, subtitle "Last played {n} mo ago" with n = days ~/ 30, at least 2.
  - Greeting: 05:00–11:59 "Good morning", 12:00–17:59 "Good afternoon", otherwise "Good evening".
  - The tile kinds that count are `album`, `artist`, `playlist`, `liked`.
- **UI strings (exact):**
  - Section titles: "Continue listening", "Shuffle All", "Shuffle Liked", "On Repeat", "Recently Added", "Rediscover", "Never Played".
  - Card subtitles: "{n} plays" and "Song {i} of {n} · {title}".
  - Empty state: "Your music lives here" / "Import files you already have, or find songs on YouTube." with the buttons "Import Music" and "Search Online".
  - Stats placeholder: "Stats are coming" / "Listening time, top artists and more arrive in the next version."
  - Load error: "Could not load Home".
  - Sub-tabs: "For You" | "Stats".
- **Back labels:** every screen opened from Home gets the back label `'Home'`, never the greeting.
- **Songs played from Home rows** use `QueueSource(QueueSourceKind.other, '<section title>')`.
- **Commits:** every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage specific paths only, because an untracked `.claude/` exists.

## Review Focus

1. **An album renamed with Edit Info after it was played:** its old tile disappears (the key no longer resolves), and the fill-up takes the free slot. → Task 2 test `renamed album drops out and fill-up takes its place`.
2. **One playlist played many times:** it gives one tile, not several. → Task 1 test `recent sources are distinct and newest first`.
3. **Library with songs but no plays, no likes, no playlists (the day of the update):** the tiles come only from Recently Added albums, On Repeat and Rediscover are hidden, and Never Played shows songs. → Task 2 test `young library without history`.
4. **Playing a song from a Home row:** it never becomes a tile. Kind `other` is excluded in SQL, and the controller records the Home source label. → Task 1 test `non-source kinds are excluded` and Task 4 test `song card plays the row with an other source`.
5. **The player restored paused after a restart:** Continue listening shows that queue right away, and a tap resumes it without restarting the song. → Task 4 test `continue card resumes the paused queue`.

### Task 2: buildForYou and greeting

**Files:**
- Create: `lib/home/for_you.dart`
- Test: `test/home/for_you_test.dart`

**Interfaces:**
- Consumes:
  - `RecentSource` and `TrackPlayCount` (Task 1)
  - `Library` with `.tracks`, `.albums`, `.album(AlbumKey)` and `.artist(String)`; `Album` with `key`, `title`, `artist`, `coverFile` and `tracks`; `Artist` with `key`, `name` and `avatarCover`
  - `PlaylistView` with `id`, `name` and `createdAt`; `Track` with `addedAt`, `playCount`, `lastPlayedAt` and `likedAt`
- Produces:
  ```dart
  sealed class HomeTile { String get title; }
  final class AlbumTile extends HomeTile { AlbumTile(this.album); final Album album; }
  final class ArtistTile extends HomeTile { ArtistTile(this.artist); final Artist artist; }
  final class PlaylistTile extends HomeTile { PlaylistTile(this.playlist); final PlaylistView playlist; }
  final class LikedTile extends HomeTile { } // title 'Liked Songs'
  class SongCard { const SongCard(this.track, this.subtitle); final Track track; final String subtitle; }
  class ForYou {
    final List<HomeTile> tiles;            // <= 6
    final List<SongCard> onRepeat;         // <= 50 (rows show the first 10)
    final List<Album> recentlyAdded;       // <= 50
    final List<SongCard> rediscover;       // <= 50
    final List<SongCard> neverPlayed;      // <= 50
    bool get isEmpty;                      // all lists empty
  }
  ForYou buildForYou({required Library library, required List<PlaylistView> playlists, required List<Track> liked,
      required List<RecentSource> recent, required List<TrackPlayCount> topRecent, required DateTime now});
  String greeting(DateTime now);
  const homeRowLimit = 10; const homeListLimit = 50;
  ```

- [ ] **Step 1: Write the failing tests.** Build the library with `Library.from([...track(...)])` from `test/support/fakes.dart`, and use `now = DateTime(2026, 11, 24, 20)`.
  - `greeting boundaries`: 04:59 gives "Good evening", 05:00 "Good morning", 11:59 "Good morning", 12:00 "Good afternoon", 17:59 "Good afternoon", 18:00 "Good evening".
  - `tiles resolve recent sources in order`: the recent sources album, playlist, liked and artist resolve to the matching tile types in that order, with an album key split on `\u0000`.
  - `renamed album drops out and fill-up takes its place`: a recent album key that matches no album is skipped. The fill-up order is Liked (when anything is liked and it is not shown yet), then playlists by `createdAt` descending, then Recently Added albums, with no duplicates and at most 6.
  - `Liked tile only when something is liked`: a recent `liked` source with no liked songs gives no tile.
  - `on repeat uses the 30-day counts`: 4 resolvable top tracks give cards with subtitle "{n} plays", and deleted track ids are skipped.
  - `on repeat falls back to all-time play counts below 4 songs`: 2 top tracks and 5 songs with `playCount > 0` give the all-time list, sorted by `playCount` descending and then `lastPlayedAt` descending, with the all-time counts as subtitles.
  - `recently added orders albums by their newest track`.
  - `rediscover thresholds`:
    - included: `playCount` 3, last played 61 days ago, subtitle "Last played 2 mo ago"
    - excluded: `playCount` 2
    - excluded: last played exactly 60 days ago
    - included: 125 days ago gives "Last played 4 mo ago"
    - sorted by `playCount` descending
  - `never played is newest added first`: the subtitle is the artist (`displayArtist`).
  - `young library without history`: no plays, no likes and no playlists. The tiles are Recently Added albums only, `onRepeat` and `rediscover` are empty, and `neverPlayed` holds the songs.
  - `lists are capped at 50`.
